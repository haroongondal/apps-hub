## 3. Decisions

- Layout: `apps/pdf-editor-mobile` (Expo), `apps/pdf-editor-desktop` (Electron), `packages/pdf-editor-engine` (shared editor HTML/JS), `apps/design-editor` (Electron).
- Electron Playwright e2e suites live under `test:e2e` (they open windows); `pnpm test` stays headless.
- `packages/ui` = the design system. Tokens in pure TS (`src/tokens.ts`); RN components (`src/components.tsx`); `web/tokens.css` generated by `scripts/build-css.ts` (staleness test) + hand-written `web/base.css` for Electron/HTML.
- Typeface: Atkinson Hyperlegible Next + Mono (OFL, vendored TTFs in `packages/ui/fonts`), chosen for at-a-glance legibility of IPs/versions.
- Each brand = a hue for the tinted neutrals + an accent taken from its launcher icon (netlens cyan, opentunnel mint, store amber, pdf red, design violet). Light + dark, follows the system.
- Design concept "pocket instruments": inset grouped lists with hairlines (not card grids), one large mono Readout as the signature element, accent only for the primary action and live state, sentence case, no emoji icons.
- Store icon: amber crate holding three tiles in the sibling apps' colours; source `apps/store/assets/icon.svg`.
