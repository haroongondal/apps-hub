Third-party code in this folder
================================

GifEncoder.kt is a port of gifenc 1.0.3, https://github.com/mattdesl/gifenc
---------------------------------------------------------------------------
GifEncoder.kt is a Kotlin port of gifenc's src/index.js (header, logical screen descriptor, colour table, NETSCAPE
loop extension, graphic control extension, image descriptor) and src/lzwEncode.js.

Quantizer.kt is NOT a port
--------------------------
gifenc's quantizer (src/pnnquant2.js) is "modified from" PnnQuant.js by Miller Cy Chan, whose LICENSE file is the
Mozilla Public License 2.0, and whose header credits Mark Tyler and Dmitry Groshev (mtPaint). That is not the MIT
licence the dependency table in docs/design-editor/SPEC.md section 3 assumes for gifenc, so Quantizer.kt is an
original median-cut quantizer instead and carries no code from either project.

----------------------------------
dev.ffmpegkit-maintained:ffmpeg-kit-min 8.1.7 (FFmpeg n8.1.2, LGPL-3.0, no GPL libraries) is used unmodified through
Gradle, only by FfmpegRunner.kt for volume, reverse and stabilize. Its licence text ships inside the AAR (res/raw/license.txt).
