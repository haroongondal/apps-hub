# OpenTunnel VPN & Privacy Guard

Zero-registration, zero-telemetry VPN client that aggregates academic and
community relays (VPN Gate) alongside user-supplied WireGuard nodes.

Scaffolded for [OpenCode](https://opencode.ai) with GLM 5.3 Flash. The four
implementation phases live in `.opencode/commands/` and are invoked as
`/phase1` … `/phase4`.

## Model configuration

`opencode.jsonc` is the V2 project configuration (the V1 `.opencode.json` shape
from the brief is not loaded by OpenCode V2 and would be ignored).

- Default: `opencode/glm-5.3-flash-free`, verified present in the local catalog.
- Optional: `z-ai/glm-5.3-flash` through `https://api.gate.ai/openai/v1`, with
  `ZAI_API_KEY` / `GATE_API_KEY` / `OPENAI_API_KEY`. Run `/models` to switch.
- `compaction.auto` is enabled; the 1M-token context is declared on the z-ai
  model entry.

compatibility with the original prompt suite.

## Verified corrections to the original brief

1. **OpenCode config was V1-shaped.** V2 uses `opencode.jsonc`, `providers`,
   `model` as `provider/model`, `shell` as a string, and `compaction.auto`
   instead of `autoCompact`. `.opencode.json` is not a V2 filename.
2. **The exact model ID was not in the catalog.** `z-ai/glm-5.3-flash` is not
   listed; `opencode/glm-5.3-flash-free` is. Both routes are configured.
3. **The VPN Gate endpoint is slow and supports HTTPS.** It is ~1.3 MB, and a
   test fetch moved only 369 KB in 25 s over HTTP. A 15-second total timeout
   would always fail, so the ingestion contract uses a 15 s connect timeout and
   a 120 s receive timeout, HTTPS first. Cached nodes render immediately.
4. **CSV comma splitting is unsafe.** The base64 payload is the last column and
   contains no commas. Parse from the final comma and fold any extra commas into
   the message/operator field instead of shifting column 14.
5. **`Builder.allowBypass(false)` does not exist.** Android opts out of bypass by
   not calling `allowBypass()` at all. The OS "Block connections without VPN"
   setting is not programmable; the app must deep-link to
   `Settings.ACTION_VPN_SETTINGS`.
6. **The native package path is `com.opentunnel.open_tunnel_vpn`**, not
   `com.opentunnel.vpn`. The service declaration and Pigeon Kotlin output use the
   real path.
7. **VPN Gate requires a scoped cleartext exception** for its HTTP fallback
   (`android/app/src/main/res/xml/network_security_config.xml` and the iOS ATS
   exception). HTTPS remains the primary transport.
8. **Licensing is a release blocker.** `ics-openvpn` is GPLv2 and
   OpenVPNAdapter/OpenVPN 3 is AGPLv3; shipping either in a proprietary build
   triggers source-disclosure obligations. WireGuardKit is MIT. Decide before
   distribution.
9. **`sqlite3_flutter_libs` is end-of-life.** The resolved package was the
   `0.6.0+eol` no-op tombstone. SQLite 3.x now ships through Dart native assets,
   so the scaffold uses `sqlite3: ^3.8.0` directly and removes the obsolete
   package.

## Phase 1 implementation notes

- `lib/core/models/vpn_node.dart` — immutable node; sha256 identity over
  `ip:port`; `speedMbps` / `uptimeSec` getters; upstream seconds stored as
  milliseconds.
- `lib/core/network/vpngate_service.dart` — endpoint sources with HTTPS first,
  15 s connect / 120 s receive timeouts; header/footer markers skipped;
  line-at-a-time decoding from the response stream (no full-body string);
  whitespace-tolerant base64 with padding repair; `remote`/`proto` extraction
  with documented 1194/udp defaults; sanitizer that strips legacy
  `cipher`/`comp-lzo` and injects the 2.6+ `data-ciphers` pair exactly once
  after the `client` preamble; `detectVpnProtocol` keyed on payload content.
- `lib/core/network/latency_prober.dart` — bounded worker pool (default 8),
  short-timeout TCP handshakes destroyed immediately, failed probes fall back
  to the static ping, results are new node copies ranked by the contracted
  fitness formula.
- `lib/core/database/app_database.dart` + generated code — Drift table keyed on
  the sha256 identity with `replaceAllNodes` (atomic replace + eviction) and
  `loadNodes` (fitness-ordered, config column withheld from list reads).
- `test/` — 19 tests, all green; no unit test touches the live network.

## Privacy invariants

- No accounts, analytics, telemetry, or remote logging.
- VPN Gate parsing, base64 decoding, and latency scoring run in the Dart UI
  process only.
- The iOS extension reads one active config from the App Group and stays below
  12 MB peak (15 MB hard OS ceiling).
- Cached nodes live in local SQLite/Drift and disappear on uninstall.
- `.env` is ignored; no keys in source or fixtures.

## Threat model and upstream terms

"Zero telemetry" describes this app, not the exit relay. VPN Gate nodes are
operated by volunteers and academic institutions; an operator can observe
traffic metadata and, without TLS, content. The UI must not claim that free
relays are anonymous or log-free. Some nodes are explicitly marked
"Academic Use Only" in the upstream `Operator`/`Message` fields, and VPN Gate's
terms still apply. Review both before distributing or monetising the app.

## Licensing and release blockers

- `ics-openvpn` is GPLv2; OpenVPNAdapter / OpenVPN 3 Core is AGPLv3. A
  proprietary App Store build that links them must comply with source-disclosure
  obligations.
- WireGuardKit is MIT.
- App Groups and Network Extension entitlements require a paid Apple Developer
  team.
